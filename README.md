# 关于 sly 的有趣问答

一个进门要先对暗号的静态小站。纯 HTML + CSS + JS，零依赖、无需构建，双击 `index.html` 就能跑。

## 目录

```
index.html                 三个界面：门禁 / 站内 / 答题闯关（同一页切换）
assets/style.css           站内样式
assets/quiz.css            门禁的性别按钮 + 答题闯关样式
assets/board.css           留言板 / 改进建议 / 夸夸板样式
assets/app.js              门禁逻辑（答案、提示语都在顶部 CONFIG 里）
assets/quiz.js             答题闯关逻辑（抽题、判分、错题回顾）
assets/board.js            三个板子的逻辑（读写留言、判断本地还是共享）
assets/question-bank.js    题库（自动生成，别手改）
问题库/                    题库源文件（你自己往里写题的地方）
问题库/悠阳的近况/*.txt      一类一个文件夹，文件夹名就是分类
问题库/悠阳的爱好/*.txt
问题库/悠阳的习惯/*.txt
```

## 现在能跑通的东西

**门禁（三道题）**
- 第 1 题「请输入我的全名（sly）」：答对放行；答错显示 `小坏蛋快去私信问问我` + 卡片抖动
- 答错 3 次后追加一句小提示（可改）
- 第 2 题「你的性别」：男生 / 女生 / 保密，用来决定站内怎么称呼你（兄弟 / 姐妹 / 朋友）
- 第 3 题「你和我有关的经历」：答案随意，但不能留空
- 第 1 题答对后回车会跳到下一题；答案容错（忽略空格、标点、英文大小写）
- 通过后淡出淡入切到站内，顶部显示「已验证进入」；「重新上锁」清掉记录回到门禁
- 通过记录 `{note, gender, at}` 存 localStorage，同一浏览器下次免答

**第一部分 · 答题闯关**
- 先选一条线：「悠阳的近况」或「悠阳的爱好」
- 系统自动配上「悠阳的习惯」6 题，一共 10 题，**每次从题库里随机抽**
- 题库题不够时会自动少出几题（比如「习惯」只有 4 题，这一轮就变成 4 + 4 = 8 题），页面上会写明原因
- 每题都能「给点提示」（告诉你答案几个字、第一个字是什么）或「跳过」
- 答完给分 + 评语 + 分类分布 + 错题回顾（正确答案和你写的对照）
- 结果页可以「再来一批（同一条线）」「换一条线」「回首页」

**第二部分 · 留言板 / 第三部分 · 改进建议 / 第四部分 · 夸夸板**
- 三个板子长一样：写内容 + 署名（可以空着，空着就用门禁里选的称呼，比如「一位姐妹」）
- 留言按时间倒序排，最新一条在最上面，每条显示署名和「刚刚 / 3 分钟前」
- 自己发的那条右边有个「撤回」，要点两下（第一下变成「确定撤回？」）才会真删
- 空内容、超过 500 字、连着发太快都会被拦住并给出提示
- 页面自己判断用哪种模式，顶部那条提示会写明现在是哪种：

| 模式 | 怎么进 | 留言存在哪 | 别人能看见吗 |
| --- | --- | --- | --- |
| 本地模式 | 直接双击 `index.html` | 浏览器 localStorage | ❌ 只有你这台电脑看得见 |
| 共享模式 | 双击 `启动服务.bat` | `数据/board.json` | ✅ 同一个网址打开的人都看得见 |

- 共享模式下页面每 20 秒自动取一次新留言，也可以点提示条右边的「刷新」
- 共享模式给你两个网址：`http://127.0.0.1:8080`（只有本机）和 `http://192.168.x.x:8080`（同一个 WiFi 下的人都能开）
- 想让外网的朋友也能看，得把这个服务放到服务器上或者做端口映射；关掉那个黑窗口就等于关站
- 同一个 IP 3 秒内只能发一条（防刷屏），每个板子最多留 500 条

## 题库怎么改（重要）

题目不在代码里，在 `问题库/` 文件夹里，**一类一个文件夹**：

```
问题库/
  悠阳的近况/   ← 写这里面的题就归到「近况」
  悠阳的爱好/
  悠阳的习惯/
  _灵感/        ← 我写的参考题，下划线开头，不会被抽到
```

文件夹里随便建多少个 txt 都行（现在那种 `新建 文本文档.txt` 也可以），每个 txt 里**一题两行**这样写：

```
1 我最近最大的花销是什么？
答案 自行车
```

规则：

- 行首的序号（`1`、`1.`、`1、`、`1）`）会被自动去掉
- 答案那一行的 `答案` 两个字可以写 `答` / `答案` / `A:`，后面就是正确答案
- 答案后面的括号是**备注**，答完题会显示出来，很好用：
  `答案 校园跑（每天都跑，多少你别问）` → 备注就是「每天都跑，多少你别问」
- 另外也支持**一行一题**的老写法，想写别的说法就用它（有别的说法也算对）：
  ```
  问题 || 正确答案 || 别的说法 || 还可以有更多说法
  ```
- `#` 开头的一行是注释，不会被当成题目
- 判分很宽松：忽略空格、标点、英文大小写；你的回答里**包含**正确答案也算对（答案至少 2 个字时）
- 答案先写「我想不出来了」「【待填】」「没想好」这类占位，那题会被跳过、不抽给答题的人，页面上会提示还有几题没写答案
- 文件名带「说明」「模板」「示例」「readme」的 txt 会被跳过

改完 txt 之后，**双击 `更新问题库.bat`**，它会重新生成 `assets/question-bank.js`，
然后回到浏览器按 F5 就能看到新题。它会告诉你每个文件读到几题、每个分类有几题可用；
题量不够只提醒不报错（答题时自动少出几题），只有「近况」和「爱好」都是空的时候才会拦下来。

## 想改门禁答案，改 `assets/app.js` 顶部的 CONFIG

```js
const CONFIG = {
  answers: ['孙路遥', 'sly'],   // 第 1 题正确答案，多个都算对
  wrongText: '小坏蛋快去私信问问我',
  hintAfter: 3,                  // 答错几次给提示
  hintText: '提示：是我名字的中文全名，三个字，姓孙。',
  genderText: '选一个吧，我好知道该怎么称呼你。',
  emptyQ2Text: '这条得写点什么吧，不然我怎么知道你是谁～',
  remember: true,                // 是否记住"已通过"（公共电脑建议改 false）
  storeKey: 'sly_gate_pass_v1'
};
```

## 本地预览

双击 `index.html` 就行（本地模式）；想让留言在别人那儿也看得见，双击 `启动服务.bat`（共享模式）。

想用别的 http 服务器打开也行，但那只是本地模式：

```powershell
python -m http.server 8080   # 然后访问 http://127.0.0.1:8080
```

## 自测

```powershell
node dev/smoke-test.js    # 假 DOM 跑真实 app.js：门禁、性别、称呼、上锁
node dev/e2e/run.js       # 无头 Edge 真跑一遍：门禁 → 答题两轮 → 三个板子发帖/撤回
node dev/server-test.js   # 服务器接口：发帖、限流、撤回权限、重启后留言还在、不让外人看题库
node dev/shots/run.js     # 按真题库重新拍一套 dev/预览图/（顺带打印题库和板子现状）
```

## 注意

- 纯前端门禁 = 防君子不防小人：答案写在 JS 里，懂行的人看源码就能翻过去。
- 本地模式下门禁和答题都只在浏览器里跑，**访客写的经历不会发到任何地方**；共享模式下三个板子的留言会存到你电脑的 `数据/board.json` 里，门上那段「经历」仍然只留在访客自己的浏览器里。
- 共享模式没有账号系统，署名是自己填的，别当成实名；「撤回」靠发帖时拿到的一串 token，同一台浏览器才认。
- `更新问题库.bat` 和 `启动服务.bat` 都特意写成纯英文内容：cmd 是按系统代码页解析批处理文件的，中文容易把行拆坏，中文提示统一由 node 脚本输出。
